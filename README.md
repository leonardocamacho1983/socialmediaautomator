# Social Media Automator

Clean reset baseline for the Social Media Automator project.

This repository currently contains only Marco 0:

- a fresh Next.js App Router app;
- TypeScript and ESLint configuration;
- a minimal home page;
- a minimal health check at `/api/health`;
- reset documentation in `docs/reset.md`.

No product features are implemented yet.

## Local

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run lint
npm run typecheck
npm test
npm run build
```
